# Offline puzzle pack

`assets/puzzles/pack.bin` is generated by `tools/build-puzzle-pack.py` from the
Lichess puzzle database and read by `src/puzzles/pack.{hpp,cpp}`. The binary
format is documented in the headers of both files.

## Source

- Data: <https://database.lichess.org/lichess_db_puzzle.csv.zst>
- License: CC0 1.0 (public domain dedication) by lichess.org
- Snapshot: 2026-09-09 (HTTP Last-Modified), 304,429,328 bytes, 6,100,952 rows
- SHA-256: `95fd454bec9efe8f940d5863d5db4c57474f281a865834997bd8cb5d6a149bb9`

The date and hash are also stored in the pack header.

## Selection

1. Filter: Popularity >= 80, NbPlays >= 300, RatingDeviation <= 90
   (2,864,563 rows qualify).
2. Stratify into 52 rating buckets of 50 points from 400 to 2999 (ratings
   outside are clamped) with water-filled quotas totalling 100,000. Buckets
   400..2749 hold about 2,100 each; the sparse top buckets and the lowest one
   contribute everything they have. Within a bucket, rows are ordered by the
   first 8 bytes of SHA-256(PuzzleId), so the selection is deterministic.
3. Top up every theme to at least 200 puzzles, alphabetically by theme, again
   in hash order; `equality` needed the relaxed pool (Popularity >= 50,
   NbPlays >= 100, RatingDeviation <= 120). 1,888 puzzles were added.

## Result

- 101,888 puzzles, ratings 399..3005, 73 themes (each >= 200 puzzles)
- 5,636,879 bytes

## Rebuilding

```sh
python3 -m venv --system-site-packages .deps/pyenv
.deps/pyenv/bin/pip install zstandard
curl -L -o ~/pch-data/lichess_db_puzzle.csv.zst \
    https://database.lichess.org/lichess_db_puzzle.csv.zst
.deps/pyenv/bin/python tools/build-puzzle-pack.py --source-date YYYY-MM-DD \
    ~/pch-data/lichess_db_puzzle.csv.zst assets/puzzles/pack.bin
```

The same source file and date reproduce the pack byte for byte. The unit-test
fixture is rebuilt with
`tools/build-puzzle-pack.py --all --source-date 2026-09-09 tests/fixtures/puzzles/mini.csv tests/fixtures/puzzles/mini.bin`.
